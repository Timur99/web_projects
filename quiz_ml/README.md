# quiz_ml

Заготовка викторины по машинному обучению: `quiz.py` содержит пустой словарь `quiz`, рядом лежат HTML-шаблон и CSS. Вопросы, обработка ответов и веб-приложение пока не реализованы.

## Быстрый просмотр

Из корня репозитория:

```bash
cd quiz_ml
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [шаблон](http://127.0.0.1:8000/templates/index.html). Страница будет пустой: в её `body` пока нет содержимого. Остановить сервер: `Ctrl+C`.

Известная проблема шаблона: ссылка `static/css/main.css` разрешается относительно `/templates/`, поэтому браузер запрашивает несуществующий `/templates/static/css/main.css` и получает `404`. Сам файл доступен по `/static/css/main.css`. В заголовке вкладки пока осталось имя `Game_new_year_2024`.

## Как проверить

Пока сервер работает, в другом терминале:

```bash
curl -f -o /dev/null http://127.0.0.1:8000/templates/index.html
curl -f -o /dev/null http://127.0.0.1:8000/static/css/main.css
```

Ожидается код завершения `0` у обеих команд. Чтобы проверить Python-заготовку, из папки `quiz_ml` выполните:

```bash
python3 -c 'from quiz import quiz; assert quiz == {}; print("Заготовка загружается, вопросов пока нет")'
```

Полноценное прохождение викторины можно будет протестировать после добавления вопросов и игровой логики.
