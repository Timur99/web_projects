# wayup_first_site

Учебный лендинг часов Sportbit на HTML и CSS: главный экран, преимущества и блок с призывом к действию. `classes/index_test.html` — отдельная страница с примерами HTML, а не автоматический тест. Покупки и серверная логика не реализованы.

## Быстрый запуск

Из корня репозитория:

```bash
cd wayup_first_site/classes
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [лендинг](http://127.0.0.1:8000/) или [примеры HTML](http://127.0.0.1:8000/index_test.html). Остановить сервер: `Ctrl+C`.

## Как проверить

1. На лендинге должны отображаться логотип, часы, мяч и три преимущества.
2. Верхняя кнопка `Buy now` прокручивает страницу к блоку практики; нижняя ведёт к началу страницы. Оплата не открывается.
3. Проверьте страницу в узком окне; на странице примеров должны быть заголовки, изображение и ссылка.

Пока сервер работает, в другом терминале:

```bash
curl -f -o /dev/null http://127.0.0.1:8000/
curl -f -o /dev/null http://127.0.0.1:8000/index_test.html
curl -f -o /dev/null http://127.0.0.1:8000/css/main.css
```

Ожидается код завершения `0`. Для загрузки Google Fonts нужен интернет.
