# code_format_and_linter

Небольшой пример Python-кода для знакомства с Ruff (поиск проблем), Black (форматирование) и mypy (проверка типов). `main.py` печатает приветствие и содержит рекурсивную функцию. Веб-сервера здесь нет.

## Быстрый запуск

Из корня репозитория:

```bash
cd code_format_and_linter
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt pandas
python main.py
```

Ожидаемый вывод: `Hello World`. `pandas` нужен из-за импорта в `main.py`, хотя дальше не используется; в исходном `requirements.txt` перечислены только инструменты проверки.

## Как проверить

Из папки проекта в активном окружении выполните команды по очереди:

```bash
python -m ruff check main.py
python -m black --check main.py
python -m mypy main.py
python -c 'from main import recursive; assert recursive(0) == 1; assert recursive(3) == 7; print("Проверка функции пройдена")'
```

Ruff должен заметить неиспользуемый импорт `pandas`, Black — предложить изменение форматирования. mypy может сообщить об отсутствующих аннотациях библиотеки `pandas`; их можно установить командой `python -m pip install pandas-stubs` и повторить проверку. Ненулевой код завершения этих инструментов означает найденные замечания, а не сбой запуска проекта.

Функция сейчас считает `1 + 1 + 2 + ... + number` для неотрицательных целых чисел. Отрицательные значения приводят к бесконечной рекурсии до `RecursionError`; большие значения могут превысить предел глубины рекурсии. Команда с `assert` проверяет текущее поведение и также выводит приветствие при импорте.
