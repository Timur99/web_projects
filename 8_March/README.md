# 8_March

Поздравительная страница к 8 Марта на HTML, CSS и JavaScript. При нажатии на многоточия открываются сообщения рядом с иллюстрациями. Сборка и установка пакетов не нужны.

## Быстрый запуск

Из корня репозитория:

```bash
cd 8_March
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [страницу поздравления](http://127.0.0.1:8000/index8.html). Остановить сервер: `Ctrl+C`.

## Как проверить

1. Проверьте, что видны заголовок, картинки и оформление.
2. Нажмите каждое `...`: соответствующий текст должен раскрыться. Повторное нажатие на ту же область должно скрыть текст; во время раскрытия надпись кнопки пустая.
3. Прокрутите страницу до конца и проверьте её в узком окне браузера.

Пока сервер работает, в другом терминале:

```bash
curl -f -o /dev/null http://127.0.0.1:8000/index8.html
curl -f -o /dev/null http://127.0.0.1:8000/js/scripts.js
curl -f -o /dev/null http://127.0.0.1:8000/css/main.css
```

Все команды должны завершиться с кодом `0`. Шрифт Google Fonts загружается из интернета; без него браузер использует запасной шрифт.
