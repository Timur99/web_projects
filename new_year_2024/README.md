# new_year_2024

Новогодняя игра на Flask: пользователь выбирает ответы, переходит между сценами и может начать заново. Интерфейс оформлен с анимацией снега. Состояние игры хранится в памяти процесса и общее для всех посетителей.

## Что нужно для запуска

В репозитории **нет `story.py` с сюжетом и изображений сцен**: они исключены через `.gitignore`. Без `story.py` приложение завершится с `ModuleNotFoundError`. Восстановите эти файлы из своей локальной копии:

- `new_year_2024/story.py` должен экспортировать список словарей `story_data` с полями `id`, `name`, `text`, `image`, `options`, `next_scene`.
- `options` — словарь вариантов ответа, `image` — имя файла в `static/images/`, `next_scene` — ID следующей сцены или `None`.
- Нужна начальная сцена с `id=0`. В коде также есть особые переходы к сцене `1000` и обращение к `story_data[4]` для сцены с `id=4`; сюжет должен учитывать эту логику.

## Быстрый запуск после восстановления сюжета

Из корня репозитория:

```bash
cd new_year_2024
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install Flask
python -m flask --app app run --host 127.0.0.1 --port 5000
```

Откройте [игру](http://127.0.0.1:5000/). Остановить сервер: `Ctrl+C`.

## Как проверить

После восстановления файлов и установки Flask можно проверить первую сцену без запуска сервера, из папки проекта в активном окружении:

```bash
python - <<'PY'
from app import app
with app.test_client() as client:
    assert client.get('/').status_code == 200
    response = client.post('/exit', follow_redirects=True)
    assert response.status_code == 200
print('Первая сцена и перезапуск доступны')
PY
```

В браузере пройдите несколько сцен, проверьте загрузку картинок, выбор ответов и кнопку «Начать заново». Отдельно проверьте ответ `B` в сцене с `next_scene=1`: он должен вести к сцене `1000`.

Известная проблема: обработчик движения мыши в `static/js/scripts.js` обращается к отсутствующему элементу `.custom-cursor`, поэтому в консоли браузера возможен `TypeError`. Это существующая ошибка интерфейса.
