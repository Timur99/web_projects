## Как пользоваться инструкциями

Команды приведены для macOS/Linux и выполняются из корня репозитория, если не указано иначе. Для Python-приложений используйте Python 3.11 или 3.12; в инструкциях выбран `python3.12`. Статическим страницам достаточно `python3` и браузера. Проверить версию: `python3 --version`.

Каждое приложение устанавливает зависимости в собственную `.venv`. Запускайте проекты по одному: статические сайты используют порт `8000`, Flask — `5000`. Остановить сервер: `Ctrl+C`; выйти из окружения: `deactivate`. Если порт занят, остановите предыдущий сервер или выберите другой порт.

Готового набора автотестов в репозитории нет. В README проектов приведены ручные проверки и короткие команды для проверки доступности страниц или функций. HTTP 200 подтверждает доступность страницы, но не заменяет проверку поведения в браузере.

Файлы `git.txt`, `figma.txt` и `pep8.txt` — заметки, отдельного запуска не требуют.
